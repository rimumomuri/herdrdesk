# Security policy

HerdrDesk reads live terminal output and can send messages to coding agents, so security reports matter to us.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Report it privately through GitHub's [private vulnerability reporting](https://github.com/rimumomuri/herdrdesk/security/advisories/new) for this repository.

Include what you found, how to reproduce it, and what an attacker could do with it. We aim to acknowledge reports within 7 days and will keep you updated until a fix is released.

## Scope

In scope: the HerdrDesk app, its web UI, the bundled helper scripts in `cli/`, and the mobile relay in `mobile/`.

Out of scope: vulnerabilities in Herdr, Herdr Core or third-party components. Report those to their maintainers. If a third-party issue affects HerdrDesk, tell us as well.

## Supported versions

Only the latest commit on the default branch is supported.
